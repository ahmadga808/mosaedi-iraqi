# مساعدي العراقي — نسخة ويب للنشر من الموبايل

## ما تحتاجه
- حساب Google لإنشاء Gemini API key: https://aistudio.google.com/apikey
- حساب GitHub: https://github.com
- حساب Render: https://render.com
- ملف ZIP هذا.

## خطوات النشر
1. فك الضغط عن المشروع في هاتفك باستخدام تطبيق الملفات.
2. افتح GitHub وأنشئ مستودعاً جديداً باسم `mosaedi-iraqi` واجعله Private.
3. ارفع ملفات المشروع إلى المستودع مع الحفاظ على المسارات. يجب أن يكون `app.py` و`requirements.txt` في الجذر، وملفا الواجهة داخل `templates/` و`static/`.
4. في Render اختر New > Web Service، واربط حساب GitHub والمستودع.
5. الإعدادات:
   - Runtime: Python
   - Build Command: `pip install -r requirements.txt`
   - Start Command: `gunicorn app:app`
   - Instance type: Free
6. في Environment أضف:
   - `GEMINI_API_KEY` = مفتاح Gemini الخاص بك (Secret؛ لا تضعه في ملفات المشروع)
   - `GEMINI_MODEL` = `gemini-2.5-flash`
7. اضغط Deploy وانتظر اكتمال البناء، ثم افتح رابط `onrender.com` الذي يظهر لك.
8. جرّب سؤالاً بسيطاً: «هلا عيني، شلونك؟»

## تنبيهات
- لم يتم نشر التطبيق أو اختباره على حسابك؛ هذه ملفات جاهزة للنشر لكن قد تتغير واجهات الخدمات.
- خدمة Render المجانية قد تتوقف بعد 15 دقيقة من عدم الاستخدام، وقد تستغرق نحو دقيقة للعودة. نظام الملفات مؤقت وحدود الاستخدام الشهرية تنطبق. ليست مناسبة للاعتماد الإنتاجي.
- Gemini API لها حدود مجانية تتغير حسب النموذج والحساب والمنطقة. راقب الاستخدام في AI Studio.
- لا تشارك مفتاح API ولا تجعله عاماً. إذا انكشف، ألغِه وأنشئ مفتاحاً جديداً.
- رسائلك تُرسل إلى Google Gemini لمعالجتها. لا تدخل معلومات حساسة.
- المايك يعتمد على المتصفح والجهاز، وقد يتطلب HTTPS وصلاحية الميكروفون.
