# مساعدي العراقي — نسخة Cloudflare Workers

## محتويات المشروع
- `src/index.js`: واجهة API آمنة تتصل بـ Gemini من الخادم.
- `public/`: واجهة الموقع بالعربية واتجاه RTL.
- `wrangler.jsonc`: إعداد Cloudflare Workers مع الأصول الثابتة.

## النشر من لوحة Cloudflare (بدون بطاقة، إذا كانت الخطة المجانية متاحة لحسابك)
1. ارفع **محتويات هذا المجلد** إلى جذر مستودع GitHub `mosaedi-iraqi`، مع الحفاظ على بنية المجلدات.
2. من Cloudflare افتح Workers & Pages وأنشئ Worker متصلًا بالمستودع. يجب أن يتعرّف على `wrangler.jsonc` و`src/index.js` و`public`.
3. إن كان نموذج النشر يطلب Build command، اتركه فارغًا. اجعل Deploy command `npx wrangler deploy` إذا كانت الواجهة تتطلبه وكان المشروع متصلًا بمستودع ويدعم إعداد Wrangler.
4. بعد النشر، افتح إعدادات Worker ثم Settings → Variables and Secrets (قد تختلف التسمية).
5. أضف Secret باسم `GEMINI_API_KEY` والصق مفتاح Gemini في قيمة السر. لا تضع المفتاح في GitHub ولا ترسله لأي شخص.
6. أضف متغيرًا عاديًا باسم `GEMINI_MODEL` وقيمة `gemini-2.5-flash`، ثم أعد النشر إذا طُلب.
7. افتح رابط `workers.dev` الذي يقدمه Cloudflare وجرّب إرسال رسالة.

## تنبيهات
- لا ترفع ملف `.env` ولا تكتب مفتاح API داخل ملفات المشروع.
- استخدام Gemini قد يخضع لحصص وحدود أو تكاليف وفق حساب Google AI Studio وإعداداته.
- واجهة الإملاء الصوتي تعتمد على دعم المتصفح وصلاحية الميكروفون.
- إذا فشل النشر، أرسل صورة رسالة الخطأ بعد إخفاء أي أسرار.
